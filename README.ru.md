## ✨ Возможности

### 🔑 Управление SSH-ключами
- **Автоматическое сканирование** всех ключей из `~/.ssh/`
- **Просмотр и редактирование** содержимого публичных и приватных ключей
- **Генерация новых ключей** — поддержка Ed25519, RSA и ECDSA с настраиваемой длиной
- **Копирование в буфер обмена** — быстрое копирование публичного или приватного ключа
- **Удаление ключей** с диалогом подтверждения

### 🖥️ Управление серверами
- **Парсинг `~/.ssh/config`** с отображением всех настроенных хостов
- **Добавление серверов** через модальное окно (Host, HostName, User, Port, IdentityFile)
- **Выбор ключа** — выпадающий список с поиском для привязки SSH-ключа или создания нового
- **Автоматическая проверка соединения** — приложение тестирует SSH-подключение в фоне:
  - ✅ Если ключ установлен → отображается кнопка **«Подключиться»** (открывает терминал)
  - 🔑 Если доступа по ключу нет → отображается кнопка **«Установить ключ»** (запускает `ssh-copy-id`)
- **Обработка несовпадения fingerprint** — обнаруживает `REMOTE HOST IDENTIFICATION HAS CHANGED` и предлагает удалить старый fingerprint
- **Интеграция с терминалом** — подключение через `.command`-файлы с использованием терминала по умолчанию

### 📦 Экспорт и импорт
- **Экспорт** выбранных ключей и конфигураций серверов в единый зашифрованный архив
- Шифрование **AES-256-GCM** с выводом ключа через **Argon2** для максимальной безопасности
- **Подтверждение пароля** — при экспорте пароль вводится дважды
- **Импорт с предпросмотром** — просмотр содержимого архива перед применением
- **Запрос пароля** — автоматическое определение зашифрованных архивов
- **Контроль перезаписи** — выбор: перезаписать существующие ключи/серверы или пропустить дубликаты

### 📡 P2P-передача по локальной сети
- **mDNS-обнаружение** — автоматический поиск других экземпляров SSH Keys Manager в локальной сети
- **TCP-передача** через JSON-протокол с префиксом длины
- **6-значный PIN** для безопасного сопряжения устройств
- **Диалог отправки** — выбор ключей и серверов с подтверждением PIN
- **Входящие передачи** — принятие или отклонение с предпросмотром (бейджи ключей 🔑 и серверов 🖥)
- **Применение данных** — импортированные ключи получают корректные права (`600`/`644`)

### ⚙️ Настройки
- **Переключение темы** — Системная / Светлая / Тёмная с иконками быстрого доступа в шапке (Монитор / Солнце / Луна)
- **Выбор языка** — Русский 🇷🇺 и English 🇬🇧 с автоматическим определением системного языка
- **Сохранение настроек** — все предпочтения хранятся в `localStorage`

### 🌍 Интернационализация (i18n)
- Полная поддержка **русского** и **английского** языков во всём интерфейсе
- Система переводов на основе ключей с хелпером `t(language, "key.path")`

## 🚀 Быстрый старт

### Требования

- **Node.js** ≥ 18
- **Rust** (через [rustup](https://rustup.rs/))
- **Tauri CLI** ≥ 2.x

```bash
# Установка Tauri CLI (если ещё не установлен)
cargo install tauri-cli
```

### Установка

```bash
# Клонирование репозитория
git clone https://github.com/dbelyaeff/ssh-keys-manager.git
cd ssh-keys-manager

# Установка зависимостей фронтенда
npm install
```

### Разработка

```bash
# Запуск dev-сервера с горячей перезагрузкой
npm run tauri dev
```

### Сборка для продакшена

```bash
# Создание продакшен-сборки
npm run tauri build
```

Готовое приложение будет доступно в `src-tauri/target/release/bundle/`.

## 🔐 Безопасность

- **Шифрование**: архивы шифруются AES-256-GCM. Ключ шифрования выводится из пароля пользователя с помощью Argon2id с рандомной 16-байтной солью.
- **Безопасность памяти**: чувствительные данные (пароли, ключи) обрабатываются в Rust с использованием крейта `zeroize` для безопасной очистки памяти.
- **Без внешнего сетевого доступа**: приложение взаимодействует только с локальными SSH-инструментами (`ssh`, `ssh-keygen`, `ssh-copy-id`) и устройствами в локальной сети (mDNS + TCP). Никакие данные не отправляются на внешние серверы.
